# Phase 3: The Native Reasoning Era (Late 2024–2026+)
Focus: Moving reasoning from the prompt layer directly into the neural network's weights via Reinforcement Learning (RL).

## Models:
- **OpenAI o1 Series (Sept 2024)**: The first massive system trained via large-scale RL to natively produce long, internal CoT chains (hiding the thought tokens behind a safety policy before returning the final text).
- **DeepSeek-R1 (Jan 2025)**: Validated that reasoning capabilities (like self-correction, backtracking, and mathematical verification) could emerge natively using pure Reinforcement Learning without human-annotated reasoning data. R1 open-sourced its full visible thought chains.
- **MAKER & Massively Decomposed Processes (2025–2026)**: Combines massive multi-agent systems and task decomposition to run millions of consecutive reasoning steps with zero errors, correcting context collapse in ultra-long horizons.
